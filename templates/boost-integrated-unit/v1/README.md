# 升压一体机测试方案标准模板

当前标准来自 2026-11-03 用户优化文件。首页是基础信息及第 1～4 章的内容来源，正文仍使用 A 列标题、B–I 内容、J 列格式。填写说明和首页不会生成 5.x 章节。

首页字段使用 `sop_<field>` 命名区域：完整标题 A1、适用范围 A6、版本 A42、归档年月 D42、拟制/审核/标准化/批准 C45:C50、标题栏名称 E45、编码 E49、所属产品 K49、电子文件名 C52。电子文件名为必填独立字段。参考文献 A7、环境 C9:J10、仪器 C14:J34 另有命名区域；保留结构和合并单元格，直接修改其内容。数量使用文本，避免 `1/1` 被 Excel 转为日期。

正文列表在同一标题小节内连续编号，经过说明、图片、表格或字母子项不重置；新标题重置，新数字父项下的字母子项从 a. 开始。无所属列表的缩进段落按普通正文对齐。

更新模板：`python tools/build_boost_input_template.py --source <用户优化.xlsx>`。不带 source 时规范化当前标准。母版仍由 `tools/build_boost_master.py` 从私有案例重建；两者均保留升压专用格式修正。`tools/verify_boost_home.py` 生成原生 Word 样例、PDF、续号与两位数编号审计。

本次母版已按用户生产发布指令登记当前 `approved_master_sha256`；部署时会自动核对批准哈希。以后重建或修改母版需重新复核，不能沿用旧哈希。历史源文件和生成快照不改写，旧文件仍可使用原基础信息表单。
