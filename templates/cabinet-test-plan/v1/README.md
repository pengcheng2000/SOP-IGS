# 工商业柜测试方案 v1

`input-template.xlsx` 是可下载的标准填写模板；`master.docx` 负责 Word 页面、字号、边框、标题栏和编号。工程内容来自 Excel，生成器不校正电气参数。`manifest.yaml` 保存母版哈希及缺项字段定义。

## 使用与字段来源

新建项目选择 **工商业柜 / 测试方案**，先上传 Excel，再确认已读取信息并补齐缺项，最后生成 Word。正文取舍在 Excel 完成；替换文件后 Excel 非空值覆盖网页补充值。自定义列表名称不改变文档标题。

首页以工作簿命名区域绑定，下面列出标准模板初始位置。使用 Excel 插入行时命名区域可随之移动；不要删除命名区域或模板版本标识。

| 字段 | 命名区域 | 初始来源 |
|---|---|---|
| 文档标题 | sop_document_title | 首页!A1 |
| 完整适用范围 | sop_scope_text | 首页!A6，移除“1.适用范围”标签 |
| 编码 | sop_document_code | 首页!E49；同时用于电子文件名 |
| 版本 | sop_document_version | 首页!A42 |
| 归档年月 | sop_archive_month | 首页!D42；规范为 YYYY-MM |
| 所属产品 | sop_product_line | 首页!K49 |
| 拟制、审核1/2/3、标准化、批准 | sop_drafter、sop_reviewer_1/2/3、sop_standardizer、sop_approver | 首页!C45:C50 |
| 参考文献 | sop_references | 首页!A7 |
| 测试环境 | sop_environment | 首页!C9:J10 |
| 仪器表 | sop_instruments | 首页!C14:J34 |

首页标题栏的重复标题只作示意；生成时统一取 A1。页码由 Word 字段计算。第 7 章版本日期使用提交生成任务时的北京时间并冻结在快照中，归档年月独立取首页。

外部大边框按纸张坐标固定，在所有页面延伸至距纸张底边 18 磅处，完整包住首页标题栏；边框不随正文或页脚高度改变。首页签署、编码和标识标题栏位于首页专用页脚，完整靠近页面底部，后续页不重复；需要在生成后的 Word 中手动编辑时，双击首页页脚即可。普通正文按原案例整段左缩进 4 字符；编号列表的编号同样缩进 4 字符，文字及续行在 6 字符处对齐，子列表再缩进一级。

全文一至四级标题统一使用 12 磅常规字重（不加粗），一级编号为 `1.`，下级保留 `5.1`、`5.1.1`、`5.1.1.1` 层级；编号统一向内留白，标题文字按层级采用悬挂缩进。所有标题的分页控制标记均清除，由独立分页段及 Word 分页检查避免标题孤立页尾。

生成前及 Word 分页后，系统逐段核对正文、表格和输入快照。多写或漏写会报 CONTENT_MISMATCH。原 Excel 在不同试验或充放电阶段复用的步骤保留，不进行全文盲目去重。

每页左侧框外显示竖排“版权所有：侵权必究”；“电子文件名：编码”仅在首页左下显示一次，编码为红色并关联已有编码字段。后续页页脚只显示页码，不重复电子文件名。

## 正文契约

- 解析版本：`cabinet-plan-v1`。正文 A–N 列为内容，O 列为格式，P 列及其右侧为说明。每张测试工作表一个二级标题；工作表顺序决定章节顺序，标题文字以行内容为准。
- 格式支持一级至四级标题、段落、缩进段落、列表、子列表、注意、表头、表格、图片。`三级标题+列表` 等组合按从左到右非空单元格对应，数量必须一致。连续表格标记形成一张表，支持跨行/跨列合并和 PNG/JPEG 图片。
- 测试章节自动编号为 5.1…；出厂配置确认为第 6 章，版本记录为第 7 章。首页、目录、填写说明、内容核对、“待整理”参考页及空页不会成为测试章节。
- 空白预留行仅用于 Excel 编辑。带“以下空白”的表格输出有效数据及一行标记；标记后有数据会报错。正文图片按锚点输出，首页的说明截图不输出。
- Excel 负责标准、电池簇、品牌、热管理、UPS 等取舍；未删去的内容均会输出。模板含示例数据，请阅读“内容核对”。BMS 表疑似错位、噪声倍率区间等保持原文并提示核对。
- 无格式的旧输入、缺失绑定、格式数量不符、越界合并、孤立四级标题、无缓存公式等会定位报错。公式需在 Excel 中重新计算并保存。
- 首页、目录各占一页 A4；正文从第三页连续排版。Word 通过书签验证页面，超限返回 `PAGE_LAYOUT_OVERFLOW`，不截断内容。

## 实现与复现

接口前缀 `/api/cabinet-plans`；四张 `cabinet_plan_*` 表由 API/Worker 启动时自动创建，迁移管理的安装也提供 Alembic `0007`。既有 bootstrap 管理的库不要直接运行整个迁移链。数据位于 `SOP_DATA_ROOT/cabinet_plan/`，应与数据库一并备份。

解析结果、字段来源、母版哈希、源文件哈希和生成日期保存为不可变任务快照。运行时仅在母版文件与 manifest 校验一致后，校准数据库中的模板元数据；新任务使用当前 manifest 哈希，已排队任务的旧快照不重写。母版内容变化会撤销旧版人工批准状态，仍需对新哈希完成复核。当前母版已按用户要求在开发机完成发布核验，`approved_master_sha256` 绑定本模板当前哈希。生产电脑直接部署，启动时自动核对并标记 approved，无需另行审核或手工批准。

原始附件放在被 Git 忽略的 `SOP_case/工商业柜测试方案/`。公开标准模板使用中性项目标题，不含首页的三张真实项目说明截图。

```powershell
.\.venv\Scripts\python -X utf8 tools/build_cabinet_plan_template.py
.\.venv\Scripts\python -X utf8 tools/build_cabinet_plan_master.py
.\.venv\Scripts\python -m pytest tests/cabinet_plan
.\.venv\Scripts\python -X utf8 tools/run_cabinet_plan_poc.py
```

Word 验收程序输出完整、删减重排、长标题、四级标题、首页超限及页脚边界超限六组 DOCX/PDF 及结果 JSON 到 `tests/output/cabinet-plan/`。浏览器验收工具为 `tools/verify_cabinet_plan_browser.py`，需开发环境安装 Playwright 和 Edge，并通过 `SOP_BROWSER_TEST_URL` / `SOP_BROWSER_TEST_PASSWORD` 指向隔离的测试服务。不要用于生产账号或生产库。
